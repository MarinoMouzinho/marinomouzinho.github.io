## Sobre
Portfólio web altamente responsivo e dinâmico, desenvolvido com foco em performance, 
design minimalista e experiência do usuário (UX). O projeto apresenta uma arquitetura
limpa em tecnologias nativas, suporte a múltiplos idiomas (Português e Inglês) e 
alternância de temas (Claro e Escuro).

__Stacks:__ HTML5 - CSS3 - Vanilla JS - Google Fonts - GitHub Pages

## Estrutura do diretório
```text
.
├── css
│   └── style.css            # Estilização global, temas, animações e responsividade
├── data
│   ├── experiences.json     # Dados estruturados das experiências profissionais
│   └── projects.json        # Dados e metadados dos projetos exibidos no portfólio
├── docs                     # Documentação de apoio (Curriculo, etc.)
├── images
│   ├── patterns
│   └── projects
├── index.html               # Estrutura principal da página
├── js
│   └── main.js              # Lógica de interatividade, temas, observadores e sliders
└── README.md                # Documentação do projeto
```
